KWE Exchange Script - last updated 21, October 2002

Install Instructions

1.  Unzip the kwe_021021.zip file.  Please make sure that the zip utility you are using retains folder information and case structure.

2.  Copy the kwexchange folder into the base www directory of your server.  This folder contains all the banner images.

3.  Copy the kwexchange.js script into the base www directory of your server.

4.  Change your html code from: 


<!--- Kickass Webcomics Exchange: http://www.pOnju.com/kwexchange.php ---!>
<SCRIPT LANGUAGE="javascript" SRC="http://www.ponju.com/kwexchange.js"></SCRIPT>
<!--- Kickass Webcomics Exchange: http://www.pOnju.com/kwexchange.php ---!>
 

to:


<!--- Kickass Webcomics Exchange: http://www.pOnju.com/kwexchange.php ---!>
<SCRIPT LANGUAGE="javascript" SRC="kwexchange.js"></SCRIPT>
<!--- Kickass Webcomics Exchange: http://www.pOnju.com/kwexchange.php ---!>


That's it!

Bug me at pOnju@ponju.com if you have any questions!
